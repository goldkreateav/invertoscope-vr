# Сборка Quest InvertoScope (Android / Horizon OS)

Этот гайд описывает сборку прилагаемого нативного проекта и установку на Meta Quest 3 **без Unity**.

## 1) Необходимые инструменты

- JDK 17
- Android Studio Iguana или новее (рекомендуется), с компонентами:
  - Android SDK Platform 34
  - Build Tools 34.x
  - NDK 26.x
  - CMake 3.22.1
- Meta Quest 3 с включённым режимом разработчика
- На шлеме включена USB-отладка
- В терминале доступна команда `adb` (из Android SDK Platform Tools)

## 2) Включение режима разработчика на Quest 3

Это нужно **один раз**, если вы ставите APK через `adb` или SideQuest. Конечным пользователям, которые ставят приложение из Quest Store / App Lab, режим разработчика **не нужен**.

### 2.1 Аккаунт разработчика Meta

1. На компьютере откройте [Meta for Developers](https://developer.meta.com/) и войдите (аккаунт Meta).
2. Примите условия для разработчиков, если система попросит.
3. Создайте или вступите в **организацию**, когда это потребует панель (нужно для функций разработчика на шлеме).

### 2.2 Приложение на телефоне и шлем

1. Установите **Meta Horizon** (мобильное приложение для Quest) на телефон и войдите **под тем же** аккаунтом Meta, что и на шлеме.
2. Включите Quest 3 и убедитесь, что шлем отображается в приложении в списке устройств (при необходимости — сопряжение, одна сеть Wi‑Fi).

### 2.3 Включение режима разработчика

1. Откройте на телефоне **Meta Horizon**.
2. Откройте **Устройства** (или **Меню** → ваш шлем) и выберите **Quest 3**.
3. Откройте **Настройки шлема** (точные названия зависят от версии приложения).
4. Найдите **Режим разработчика** (иногда в **Дополнительно** / **Расширенные**).
5. Включите **Режим разработчика**.

Если переключателя нет:

- Убедитесь, что шлем виден в приложении и прошивка обновлена.
- Убедитесь, что вы завершили регистрацию разработчика и настройку организации на [developer.meta.com](https://developer.meta.com/).
- После включения перезагрузите шлем.

### 2.4 USB-отладка (для `adb`)

1. Подключите Quest 3 к ПК кабелем USB‑C **с передачей данных**.
2. Наденьте шлем: при запросе **Разрешить отладку по USB?** выберите **Разрешить** (при желании — **Всегда разрешать** для этого компьютера).

После этого команда `adb devices` должна показывать устройство (см. раздел 6).

## 3) Открытие проекта

1. Запустите Android Studio.
2. Выберите **Open** и укажите каталог:
   - `C:\Users\algoi\Downloads\1234\VIBE-CODING EXAMPLE`
3. Дождитесь синхронизации Gradle.

Если Android Studio предложит доустановить SDK / NDK / CMake — согласуйте установку недостающих компонентов.

## 4) Настройка SDK и NDK

В Android Studio:

1. Откройте **File > Settings > Android SDK** (на macOS: **Android Studio > Settings**).
2. Убедитесь, что установлен **Android 14 / API 34**.
3. На вкладке **SDK Tools** проверьте:
   - Android SDK Build-Tools
   - Android SDK Platform-Tools
   - NDK (Side by side)
   - CMake 3.22.1

## 5) Сборка APK

### Вариант A (через Android Studio, рекомендуется)

1. Вариант сборки: `debug`.
2. Меню **Build > Build APK(s)**.
3. Дождитесь успешной сборки.
4. Путь к APK:
   - `app/build/outputs/apk/debug/app-debug.apk`

### Вариант B (командная строка)

Терминал в Android Studio (или обычный терминал с настроенным Gradle):

```bash
./gradlew assembleDebug
```

В PowerShell на Windows:

```powershell
.\gradlew.bat assembleDebug
```

Если файлов Gradle Wrapper нет, один раз сгенерируйте обёртку из окна Gradle в Android Studio или при установленном Gradle:

```bash
gradle wrapper
```

## 6) Подключение Quest 3 и проверка устройства

1. Подключите Quest 3 по USB‑C.
2. Наденьте шлем и подтвердите запрос отладки по USB.
3. В терминале выполните:

```bash
adb devices
```

Ожидается: одно устройство в состоянии `device`.

## 7) Установка APK на Quest 3

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 8) Первый запуск и разрешения камеры

1. Запустите **Инвертоскоп** из раздела неизвестных источников (Unknown Sources).
2. При запросе выдайте разрешения камеры:
   - `android.permission.CAMERA`
   - `horizonos.permission.HEADSET_CAMERA`

Если диалог не появился:

1. Откройте настройки приложения на шлеме и вручную включите доступ к камере.
2. Перезапустите приложение.

## 9) Чеклист проверки после запуска

Сразу после запуска проверьте:

1. Приложение открывается без мгновенного вылета.
2. Строка статуса OpenXR показывает результат проверки среды (загрузчик найден или явное сообщение).
3. В режиме разделённого экрана виден живой поток с камеры:
   - левый поток слева,
   - правый поток справа (или дублирование одного потока, если система отдаёт одну камеру).
4. Элементы управления слева влияют только на левую половину:
   - ползунок поворота крутит картинку,
   - переключатели зеркала по осям.
5. Элементы управления справа влияют только на правую половину.
6. Пресеты и сброс работают, рендер не зависает.
7. После выхода и повторного входа поток камеры возобновляется.

## 10) Ограничения этого прототипа

- Доступность камер зависит от политики Horizon OS и прошивки.
- На части сборок ОС приложению может быть доступен только один поток — тогда одна и та же картинка показывается в обеих половинах.
- Проверка OpenXR в коде подтверждает наличие загрузчика и шлема; отрисовка в прототипе — через GLES, раздельные половины экрана.

## 11) Что собрать при ошибках

Снимите лог:

```bash
adb logcat | grep -i -E "invertoscope|camera|openxr"
```

Передавайте вместе с отчётом:

- текст ошибки сборки (если сборка не прошла);
- вывод `adb install`;
- фрагмент `adb logcat` вокруг запуска приложения.
