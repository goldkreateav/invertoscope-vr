# Сайт услуг списывания

Одностраничный HTML+CSS сайт с карточками услуг, ценами и намеренно «плохим» дизайном.

## Как загрузить на GitHub

1. Перейдите на [github.com/new](https://github.com/new)
2. Введите название репозитория (например, `uslugi-spisyvaniya`)
3. Нажмите **Create repository** (не добавляйте README, .gitignore или лицензию)
4. В папке проекта выполните:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git branch -M main
git push -u origin main
```

Замените `ВАШ_ЛОГИН` и `НАЗВАНИЕ_РЕПО` на свои данные.
